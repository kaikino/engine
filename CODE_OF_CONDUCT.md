# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, be constructive, assume good faith, and remember
that the person on the other side of the pull request is a person. Harassment,
discrimination and personal attacks are not tolerated.

Report concerns privately to the maintainer through the contact listed on
the GitHub profile of the repository owner. Reports are handled in
confidence.
